SkyCat

A small command-line frontend for Quickemu that downloads and runs prebuilt virtual machines.

Get started

Use a Linux system with Python 3 installed. Download skycat.py, then initialize SkyCat once:

python3 skycat.py init

Download an available VM, then run the same command again to start it:

python3 skycat.py run ubu14

Available VMs

  • ubu14 - Ubuntu 14.04 LTS
  • ade1b6 - Adelie Linux 1.0 beta 6

Commands

  • run <os> — download an image if needed, then run it.
  • delete <os> — remove a downloaded image after confirmation.
  • conf <os> <setting> <value> — change a VM setting such as ram, disk_size, or cpu_cores.
  • server <os> — add the script's predefined port forwards.

Run python3 skycat.py --help for the usage details. Be careful when editing VM configuration; unsupported changes can stop a VM from working.
